Adoption pre-release built from real Consumer feedback ([#67](https://github.com/mnaimfaizy/agent-kit/issues/67)). No reusable-workflow inputs, secrets or permissions changed; upgrade the `uses:` pins and the copied files together, as always.

### Consumer action

- **Recommended:** re-copy the Kit-owned paths with the new loop in `docs/getting-started.md` step 3. It deletes each path before copying it, so files an earlier tag shipped and this one removed no longer linger. Your own skills in `.claude/skills/` are left alone.
- **Recommended before granting `extra_allowed_tools` that run repository code:** apply the rulesets in `docs/repository-hardening.md`.

### Added

- `kit-owned-paths.txt`: the one list of **Kit-owned paths**, read by the quickstart, `docs/adopt.md` and the upcoming `@mnaimfaizy/agent-kit` CLI. This is the first tag that has it; the CLI will refuse earlier tags.
- `docs/repository-hardening.md`: `gh api` commands for rulesets the Claude GitHub App cannot bypass, plus a deploy-key pattern for personal-account repositories that push release tags.
- `examples/setup-presets/`: `setup_commands` presets for Python, Node.js, both, and a Redis service container, using the runner tool cache.
- A fifth Portable skill, `explainer`, for **Explainer Pages**. Optional; no First-class flow uses it.
- A "Decisions you'll make" checklist in `docs/getting-started.md`.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.11` and copy every path in `kit-owned-paths.txt` from the same tag. See `docs/adopt.md`.
