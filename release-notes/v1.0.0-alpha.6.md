Security pre-release for [GHSA-pwx3-m47m-qfm5](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-pwx3-m47m-qfm5) and [GHSA-8787-cwm5-fvcj](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-8787-cwm5-fvcj). It hardens read confinement, the agents' tool grants, and which job runs agent-authored code. Upgrade the `uses:` pins and the copied files together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` and `.github/agent-pipeline/` from this tag.
- Implement runs `setup_commands` twice (before the agent and in the new read-only `verify` job); keep them idempotent. `verify_commands` run with `bash -c`, not a login shell.
- Security audit `full` mode refuses `head_sha` / `base_sha`; use `mode: pr` for pull requests.
- The implement job needs Docker (GitHub-hosted `ubuntu-latest` has it). The email notifier now verifies the SMTP server's certificate.

### Security

- Read confinement resolves symlinks, runs from a staged read-only hook checked by digest, refuses `.git` for every read tool, and covers the implementer.
- No agent holds `git diff` / `log` / `show`, `gh pr comment`, or `gh pr create`.
- Agent-authored code runs only in jobs without write or OIDC credentials: `verify_commands` moved to their own `contents: read` job.
- Security audit `full` mode audits only the commit it was dispatched on; the email notifier verifies TLS and runs Python isolated.
