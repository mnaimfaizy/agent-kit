Second public Agent-kit pre-release. Callers pinned to `v1.0.0-alpha.1` need to update workflow inputs, secrets, and the files they copy from the tag.

### Changed

- Plan, implement, review, and security-audit jobs run Claude Code with the Issuebridge workflow controls: SHA-pinned action, job-token GitHub auth for every job except the implementer, `persist-credentials: false`, a PreToolUse hook that confines Read/Grep/Glob to the workspace, reviewed tool allowlists, staged credentialed audit scripts, and an advisory-token preflight before the audit agent runs.
- Review is a pull-request job. Pass `pr_number`, `head_sha`, `base_sha`, and `base_ref`.
- Callers pass `claude_code_oauth_token`. The audit Caller also passes `github_token`.
- Copy `.github/agent-runtime/` from this same tag. Plan, review, and audit load that confinement hook from the Consumer checkout.

Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.2` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
