Security pre-release for [GHSA-hg89-9pp4-v549](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-hg89-9pp4-v549). The implementer can no longer write git's configuration or hooks, or Claude Code's project settings, and the read-confinement hook judges every expansion of a Glob brace pattern. Upgrade the `uses:` pins and the copied files together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` from this tag. Implement stages two new files, `confine-writes-to-worktree.mjs` and `check-git-config.mjs`, and fails before the agent starts if either is missing.
- **Recommended:** check that your default branch's ruleset stops the Claude GitHub App from merging its own pull request. A pull-request rule with zero required approvals does not; an `update` rule that only maintainers can bypass does. See this repository's `CONTRIBUTING.md` (Branch protection) for a worked example.

### Security

- A new staged hook keeps the implementer's file-writing tools inside the working tree, out of `.git`, and away from `.claude/settings.json`, `.claude/settings.local.json`, and `.mcp.json`, judged on the path with symlinks resolved.
- Before and after the agent, and in the push guard before it runs git, implement checks `.git/config` against an allowlist and `.git/hooks` for anything but samples. The git calls after the agent run with fsmonitor and hooks turned off.
- Plan and audit are denied edits to `.claude/` and `.mcp.json`, so an agent cannot widen its own tools mid-session.
- The read-confinement hook expands Glob brace groups and judges every expansion, and refuses a pattern whose braces it cannot expand.
- Hardening: implement closes a non-draft implementer PR, and its post-agent workflow-edit check also covers `.github/actions/`.

Also in this release: review takes an optional `trusted_spec_authors` input, and implement takes optional `branch_prefix` and `branch_name_template` inputs. See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.9` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
