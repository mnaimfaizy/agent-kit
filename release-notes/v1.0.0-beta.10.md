Tenth **beta** on the `1.0.0` line, classed **Major**: `security-finding-triage` no longer edits the findings ledger, and `security-response`'s `STATUS-FORMAT.md` is gone. It ships the **Deep scan**: a third `security-audit` mode, `deep`, and the `agent-kit deep-scan` launcher, which builds, runs and probes your repository's own code inside a closed, disposable sandbox and reproduces Medium+ findings. It also gives `security-response` a **Security Response Run**, a private local board for responding to draft advisories.

### Consumer action

- **Renamed and removed names (required).** These changed in v1.0.0-beta.10, and the old names no longer work, with no fallback. Replace each one in your Callers, repository variables and settings:

  | Kind | Old                                                 | New                                       |
  | ---- | --------------------------------------------------- | ----------------------------------------- |
  | path | `.claude/skills/security-response/STATUS-FORMAT.md` | `.claude/skills/security-response/RUN.md` |

- **If you ran `security-finding-triage` on its own to keep your findings ledger current:** copy its new "Proposed ledger row" into the ledger by hand. Only a Security Response Run's `close` writes the ledger now ([#350](https://github.com/mnaimfaizy/agent-kit/issues/350)).
- **If you use `security-response`:** add `tmp/security-response/` to your `.gitignore`, or say yes when the skill offers it ([#348](https://github.com/mnaimfaizy/agent-kit/issues/348)).
- **Everything else is opt-in.** Upgrade the `uses:` pins and the Kit-owned paths together, as always. From a clean branch in your repository:

  ```bash
  npx @mnaimfaizy/agent-kit@1.0.0-beta.10 upgrade --tag v1.0.0-beta.10
  ```

  It replaces the Kit-owned paths, rewrites the Agent-kit pins, prints the `examples/` diff for you to apply to your Callers by hand, and runs the `doctor --ci` checks. It commits nothing; review `git diff` and commit.

### Deep scan (`security-audit` deep mode)

- **The `deep` mode** builds, runs and probes the repository's own code in a sandbox, reproduces Medium+ findings, and probes the Threat pack's attack paths. The report gains `Reproduced`, a prose Observation, `Open questions` and `Stopped:`. A Reproduction is never delivered as a runnable exploit ([#366](https://github.com/mnaimfaizy/agent-kit/issues/366), [ADR 0016](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-beta.10/docs/adr/0016-security-pocs-are-never-delivered-rather-than-never-produced.md)).
- **`agent-kit deep-scan`**, local by default ([#367](https://github.com/mnaimfaizy/agent-kit/issues/367) to [#372](https://github.com/mnaimfaizy/agent-kit/issues/372), [ADR 0018](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-beta.10/docs/adr/0018-a-deep-scan-runs-locally-by-default.md)):
  - It validates the **Scan recipe** (`.security/scan-recipe.yml`) as committed on the default branch.
  - It chooses a sandbox runtime from the host, or refuses, with no override: Docker Sandboxes (`sbx`), or Kata, Firecracker or gVisor on Docker Engine 28.0 or later.
  - It runs the sandbox from copy-in to teardown, with registry-only egress for setup and a cut before the agent step.
  - The real Claude Code runs behind a key-injecting model proxy on your machine, so your key never enters the sandbox.
  - Wall-clock, turn and token limits are enforced outside the sandbox.
  - One report is copied out to a private local folder. Nothing is filed or posted.
- **Verification run:** `deep-scan --verify <file> --ref <ref>` re-attempts known findings on your fix branch ([#372](https://github.com/mnaimfaizy/agent-kit/issues/372)).
- **Model and effort:** `--model` and `--effort`; the run names the model and effort asked for, and the model that answered.
- **Subscription token, opt-in at your own risk:** `--credential subscription` runs on a Claude subscription token instead of an API key ([#375](https://github.com/mnaimfaizy/agent-kit/issues/375)).
- **Opt-in CI:** `deep-scan-reusable.yml` and `examples/deep-scan-caller.yml` run a Deep scan on the default branch, on an ephemeral runner with gVisor, keeping the Public-log rule ([#373](https://github.com/mnaimfaizy/agent-kit/issues/373)).
- **Docker Engine isolation:** the sandbox's one network is `--internal` and in Docker's `isolated` gateway mode, so the host has no address on it. A relay forwards the proxy's one port, and probes check the route from the host, one under the sandbox's own runtime ([#404](https://github.com/mnaimfaizy/agent-kit/issues/404)). Docker Engine below 28.0, and Docker Desktop on macOS, are refused; a Mac uses Docker Sandboxes.

To start, read [Running a deep scan](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-beta.10/docs/security-audit.md). Use an API key from a dedicated Anthropic Console workspace with its own spend limit.

### `security-response`: Security Response Run

- A private local board in `tmp/security-response/<date>/` tracks your response to every open draft advisory, and a later session resumes it ([#348](https://github.com/mnaimfaizy/agent-kit/issues/348), part of [#344](https://github.com/mnaimfaizy/agent-kit/issues/344)).
- Every mode reconciles the run first ([#349](https://github.com/mnaimfaizy/agent-kit/issues/349)). `triage` lands `security-finding-triage`'s outcome on the board ([#350](https://github.com/mnaimfaizy/agent-kit/issues/350)). `record <what>` lands your steps from a closed set ([#351](https://github.com/mnaimfaizy/agent-kit/issues/351)).
- Draft advisories with no findings show on the board, and are closed by name ([#352](https://github.com/mnaimfaizy/agent-kit/issues/352)).
- `close` writes the findings ledger and closes the run ([#353](https://github.com/mnaimfaizy/agent-kit/issues/353)).

### Fixed

- `prepare-release.sh` no longer rewrites the `release:` field of Deprecation register entries when it bumps pins ([#361](https://github.com/mnaimfaizy/agent-kit/issues/361)).
- On gVisor, `deep-scan` now gets its brief in and its report out (through `docker exec`, not `docker cp`), and gives the agent step its model route (networks are fixed at start, never hot-plugged) ([#404](https://github.com/mnaimfaizy/agent-kit/issues/404)).
