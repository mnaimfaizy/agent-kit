Adds Claude Opus 5.5 support and fixes two implement-stage bugs found by dogfooding. No required Caller changes: move your `uses:` pins and copied files from `v1.0.0-alpha.3` to this tag together.

### Added

- **Model from a repository variable.** The example Callers pass `model: ${{ vars.CLAUDE_MODEL || 'claude-opus-5' }}`. Add that line to your Callers, then choose the model with `gh variable set CLAUDE_MODEL --body claude-opus-5-5`; no commit needed. Without it, the reusable workflows keep defaulting to `claude-opus-5`.

### Changed

- `anthropics/claude-code-action` bumped to v1.0.233 (Claude Code 2.1.228 → current). The previous pin fails instantly with `claude-opus-5-5`; this tag is required for Opus 5.5.

### Fixed

- Implement deletes its `implementer-brief.md` scratch file before your `verify_commands`, so whole-tree checks like `prettier --check .` no longer fail on it.
- Implementer PRs include `Closes #<issue>`, so review finds the Verified plan and runs its Spec axis.

Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.4` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
