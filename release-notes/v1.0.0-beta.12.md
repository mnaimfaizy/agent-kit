Security pre-release for [GHSA-3wmq-p452-fw6h](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-3wmq-p452-fw6h). Twelfth **beta** on the `1.0.0` line, classed **Minor** (per [docs/releases.md](../docs/releases.md)). Review and the PR-mode security audit now restore their runtime only from the trusted branch, and the audit no longer writes through symlinks a pull request commits. Upgrade the `uses:` pins and the Kit-owned paths together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` from this tag. It adds `security-audit.settings.json`, and the security audit refuses to start without it. The upgrade below does this, because it replaces every Kit-owned path. From a clean branch in your repository:

  ```bash
  npx @mnaimfaizy/agent-kit@1.0.0-beta.12 upgrade --tag v1.0.0-beta.12
  ```

  It replaces the Kit-owned paths, rewrites the Agent-kit pins, prints the `examples/` diff for you to apply to your Callers by hand, and runs the `doctor --ci` checks. It commits nothing; review `git diff` and commit.

- **Optional:** set the new `trusted_branch` input on your review and security-audit Callers when the branch your reviewed agent runtime lives on is not the default branch. Left empty, both use the default branch.

### Security

- **Restore anchor.** Review and PR-mode audit restored their instructions, skills and read hook from the pull request's base commit, and the audit staged its credentialed publish and notify scripts from it too. That base belongs to whatever branch the pull request targets. Both now restore from the base only when it is on the trusted branch, and from that branch's tip otherwise. The diff still uses the base, so a pull request into the default branch behaves as before.
- **Implementer guards.** The implementer's push guard, edit denies and post-agent check now also cover the Kit-owned `.github/agent-runtime/`, `.github/agent-pipeline/`, `.github/security-audit/` and `.github/agent-review-response/`. An issue that needs a change there needs a human, as for workflows.
- **Audit writes.** Before writing anything, a PR-mode audit now refuses a report directory reached through a symlink, and removes any entry already at the brief, report, transcript and CLI-log paths. The audit agent runs the write-confinement hook, so its writes are judged by where the path really resolves.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-beta.12` and copy every path in `kit-owned-paths.txt` from the same tag. See `docs/adopt.md`.
