Ninth **beta** on the `1.0.0` line, classed **Minor**: everything it adds is opt-in, and existing Callers and copied skills keep working. `orchestrate` gains a **Team Run**, `/orchestrate --spec <n> --team`, for teammates who split one spec's tickets and each run their own Chief of Staff, with a **Shared Board** on the tracker that everyone can read. It also fixes `agent-kit upgrade` and `init` refusing the manifest of v1.0.0-beta.7 and later.

### Consumer action

- **None required.** Upgrade the `uses:` pins and the Kit-owned paths together, as always. From a clean branch in your repository:

  ```bash
  npx @mnaimfaizy/agent-kit@1.0.0-beta.9 upgrade --tag v1.0.0-beta.9
  ```

  It replaces the Kit-owned paths, rewrites the Agent-kit pins, prints the `examples/` diff for you to apply to your Callers by hand, and runs the `doctor --ci` checks. It commits nothing; review `git diff` and commit.

- **To try a Team Run:** assign each of the spec's tickets to one person, and have each of you run `/orchestrate --spec <n> --team`. A run without `--team` is unchanged.

### `orchestrate`: Team Run

- **Only your tickets.** Each teammate's Chief of Staff builds only the tickets assigned to them, and lists everyone else's with their state under "Teammates' tickets (not run here)" ([#316](https://github.com/mnaimfaizy/agent-kit/issues/316), part of [#314](https://github.com/mnaimfaizy/agent-kit/issues/314), [ADR 0014](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-beta.9/docs/adr/0014-a-team-runs-shared-board-is-one-single-writer-row-per-ticket.md)). A Team Run always lands one pull request per ticket. The config gains a `tracker` key and a `team` section, both read only by a Team Run.
- **The Shared Board.** After "go", each of your tickets carries one row comment, a status card written only by you, and one state label ([#317](https://github.com/mnaimfaizy/agent-kit/issues/317), [ADR 0015](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-beta.9/docs/adr/0015-the-shared-board-is-a-published-projection-of-each-local-run-folder.md)). Rows are written only when they change, under a routine write you approve at "go". Briefs, reports, Decision Requests, the Ruling Ledger and logs stay in your local run folder. A ticket blocked by a teammate's waits until that pull request is merged.
- **One writer per row.** When a ticket is reassigned mid-run, your Chief of Staff asks whether to hand it off or ask for it back, and a hand-off pushes the branch for the new assignee to pick up ([#318](https://github.com/mnaimfaizy/agent-kit/issues/318)). A row from another run of yours is never overwritten without asking.
- **Watch the whole spec.** `--status` of a Team Run prints every ticket of the spec as a blocking tree in merge order, with a "Next moves" line. Anyone can watch with `/orchestrate --status --spec <n>`, from the tracker alone, with no run folder ([#319](https://github.com/mnaimfaizy/agent-kit/issues/319)).
- **Resume, or carry on after a lost machine.** `--resume` re-reads every ticket's assignee and brings the run back in line with the Shared Board. After a lost machine, a new Team Run takes your old rows over and restarts each unfinished ticket from its branch ([#320](https://github.com/mnaimfaizy/agent-kit/issues/320)). The git remote you name when `check` cannot tell is kept on the board, so a resume uses it too.
- **GitLab Free.** `trackers/gitlab.md` maps every tracker operation onto `glab` ([#321](https://github.com/mnaimfaizy/agent-kit/issues/321)). A GitLab spec lists its tickets as a task list in its description. Both the GitHub and GitLab mappings are at Support Level `documented`: neither has been tried by a two-person run yet ([#322](https://github.com/mnaimfaizy/agent-kit/issues/322)).

### `orchestrate` on Claude Code desktop

- The desktop harness file now records what a full run found: each session starts in the Chief of Staff's own permission mode, so messages between them are not held. On a turn the app started, a session can only be proposed as a card for you to start, and the run waits on that card instead of losing track of it. Idle notifications are addressed by the session's title.

### Fixed

- `agent-kit upgrade` and `agent-kit init` no longer refuse the manifest of v1.0.0-beta.7 and later ([#301](https://github.com/mnaimfaizy/agent-kit/issues/301)).

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-beta.9` and copy every path in `kit-owned-paths.txt` from the same tag. See `docs/adopt.md`.
