First usable Agent-kit pre-release. `v1.0.0-alpha.1` and `v1.0.0-alpha.2` are broken — GitHub rejects their reusable workflows ("Invalid workflow file") — so move any Caller pinned to them to this tag.

### Caller changes (required)

- Remove `github_token: ${{ secrets.GITHUB_TOKEN }}` from every `secrets:` block. The reusable workflows now use `github.token`, limited by your Caller's `permissions:`.
- Remove `vulnerability-alerts: read` from the audit Caller's `permissions:` (not a valid scope).
- Optional: pass `dependabot_alerts_token` (fine-grained PAT, Dependabot alerts: read) to ground `full` audits on open alerts. Without it the step is skipped.

### Fixed

- Reserved `github_token` secret name that made all four reusable workflows invalid.
- Invalid `vulnerability-alerts` permission in the security audit.
- `verify_commands` containing quotes no longer break the implement job.

### Added

- [Getting started](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-alpha.3/docs/getting-started.md) walkthrough with troubleshooting, and a generated [workflow reference](https://github.com/mnaimfaizy/agent-kit/blob/v1.0.0-alpha.3/docs/reference.md) of every input, secret, and permission.
- Examples read their Kill switch from repository variables (`CLAUDE_PIPELINE_ENABLED`, `CLAUDE_SECURITY_AUDIT_ENABLED`).

Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.3` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
