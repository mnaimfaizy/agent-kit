Security pre-release for [GHSA-pcmj-6fhc-546w](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-pcmj-6fhc-546w) and [GHSA-vrhj-cf3v-6rvj](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-vrhj-cf3v-6rvj). Thirteenth **beta** on the `1.0.0` line, classed **Minor** (per [docs/releases.md](../docs/releases.md)). The Deep scan's model proxy forwards only what the sandboxed Claude Code needs and holds its token cap against requests sent together. Grounding URLs reach only public HTTPS hosts. The confinement hooks refuse paths they cannot judge as written, and the implementer's Bash guard refuses line continuations. Upgrade the `uses:` pins and the Kit-owned paths together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` from this tag, for the changed read-confinement, write-confinement and implementer Bash guard hooks. The upgrade below does this, because it replaces every Kit-owned path. From a clean branch in your repository:

  ```bash
  npx @mnaimfaizy/agent-kit@1.0.0-beta.13 upgrade --tag v1.0.0-beta.13
  ```

  It replaces the Kit-owned paths, rewrites the Agent-kit pins, prints the `examples/` diff for you to apply to your Callers by hand, and runs the `doctor --ci` checks. It commits nothing; review `git diff` and commit.

- **If you run a Deep scan:** run it with this version (`npx @mnaimfaizy/agent-kit@1.0.0-beta.13 deep-scan`), and check your Scan recipe's `grounding` URLs. Each must be `https://`, name a public host by its DNS name (not an IP address, a single-label name or `localhost`), and answer without a redirect: name each page by its final URL. `agent-kit doctor` reports a recipe that no longer passes. Pin the recipe's `image` by digest (`name:tag@sha256:<digest>`); a tag-only image still runs, with a note.

### Security

- **Deep scan model proxy.** The proxy forwarded any `/v1/` path and method, for any caller in the sandbox, with the body passed on unread. It now forwards only `POST /v1/messages` and `POST /v1/messages/count_tokens`, only with the run's own caller key, and only a body with no server-side tool, `mcp_servers`, `container`, or content that names a URL or file for the model API to fetch.
- **Deep scan token cap.** The cap was checked only as each request arrived, so many requests opened at once all passed it. The proxy now keeps at most four in flight, and reserves each one's declared `max_tokens` plus an input estimate against the cap.
- **Grounding fetch.** Grounding URLs were fetched on your machine with redirects followed, to any address. The recipe check and the fetch now allow only public `https://` hosts, follow no redirect, and connect only to an address checked as public.
- **Confinement hooks.** The read-confinement and write-confinement hooks now refuse a path that starts with `~` or has leading or trailing whitespace, which they had judged as an in-tree name. The read hook judges each tool on its own location field, and refuses a call that carries one its tool does not use.
- **Implementer Bash guard.** The guard now refuses a line continuation (a backslash before a newline) outside single-quoted text, and judges every git invocation in a command, not only the first. The implement and review-response workflows probe it with a line continuation before the agent starts.
- **Recipe image.** `deep-scan` notes a recipe `image` with no `@sha256:` digest, since the image is pulled and built on your Docker engine, outside the sandbox runtime. The threat model now records the image as trusted input on every runtime.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-beta.13` and copy every path in `kit-owned-paths.txt` from the same tag. See `docs/adopt.md`.
