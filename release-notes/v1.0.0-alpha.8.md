Security pre-release for [GHSA-529g-7fww-6rr7](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-529g-7fww-6rr7). A pull request's `.gitattributes` can no longer stop the read-confinement hook from running in review and PR-mode audit. Upgrade the `uses:` pins and the copied files together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` from this tag. The settings now run every hook with `|| exit 2`, and each flow fails with a message if the copied settings are older.

### Security

- Before restoring the runtime from the pull request base, review and PR-mode audit pin the content-changing git attributes off and rewrite the checkout.
- Before the agent starts, every flow checks that the staged read-confinement hook refuses an out-of-tree read. Implement also checks that its push guard refuses a chained push.
- A hook that cannot run now blocks the call instead of allowing it.
- Hardening: the diffs precomputed for review and audit ignore the pull request's attributes, so no text change can show as binary.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.8` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
