Eleventh **beta** on the `1.0.0` line, classed **Major**: QA Plans move to `format=4`, which an older `manual-qa` refuses; the posted QA Report becomes a short summary with a strict header; and a scenario whose **Observes:** no single Surface can see is now refused. It ships autonomous QA in `orchestrate` (nothing asked mid-run), Run Records with a past-runs dashboard and a live board, multi-session QA videos told in Scenes, and multi-Surface `run.surface`.

### Consumer action

- **Update `qa-plan` and `manual-qa` together (required if you use them).** The QA Plan format is now `format=4` and an older `manual-qa` refuses it ([#381](https://github.com/mnaimfaizy/agent-kit/issues/381)). The posted QA Report is now a short summary, so a script that read its sections must read the header and summary instead ([#413](https://github.com/mnaimfaizy/agent-kit/issues/413)). A script that reads the MP4 summary's `session` must read it as a list.
- **Re-plan mixed-Surface scenarios.** An existing QA Plan scenario that mixes values only `api` sees with `screen` in **Observes:** is now refused by `validatePlan`; re-plan it, or split it by hand into one scenario per Surface ([#378](https://github.com/mnaimfaizy/agent-kit/issues/378)).
- **If you copy `orchestrate`:** keep `run_dir` gitignored. A run now writes Run Events, a local Run Record and `board.html` there, and `board.html` holds Activity Log prose ([#414](https://github.com/mnaimfaizy/agent-kit/issues/414)).
- **Everything else is opt-in.** Upgrade the `uses:` pins and the Kit-owned paths together, as always. From a clean branch in your repository:

  ```bash
  npx @mnaimfaizy/agent-kit@1.0.0-beta.11 upgrade --tag v1.0.0-beta.11
  ```

  It replaces the Kit-owned paths, rewrites the Agent-kit pins, prints the `examples/` diff for you to apply to your Callers by hand, and runs the `doctor --ci` checks. It commits nothing; review `git diff` and commit.

### `orchestrate`

- **Autonomous QA:** in a `go autonomous` run, approving QA in the Dispatch Plan means QA asks nothing mid-run. Facts only you know are asked once in the plan; the rest is held in a "QA held for you" list ([#413](https://github.com/mnaimfaizy/agent-kit/issues/413)). The Chief of Staff never runs QA scenarios itself, and scoped QA Delegations merge into one QA Report per head ([#536](https://github.com/mnaimfaizy/agent-kit/issues/536)).
- **Run Records:** every run keeps a Run Record, which can be uploaded to a private `github`, `gitlab` or `s3` Sink. `/orchestrate --dashboard` shows past runs, and `board.html` shows the current one live. All new `records` and `prune` config keys are optional ([#414](https://github.com/mnaimfaizy/agent-kit/issues/414)).
- **Integration review and landing:** a spec's whole integration branch is reviewed before its pull request. The new `config.mjs regate` and `config.mjs land` commands re-gate and land work, and `regate.allowed_failures` lists known baseline failures ([#478](https://github.com/mnaimfaizy/agent-kit/pull/478)).
- **Foreground watch** is strictly read-only, fenced by a `watch.gen` generation id, and `--resume` verifies its sources ([#535](https://github.com/mnaimfaizy/agent-kit/issues/535)).
- **Google Antigravity** and the `github` Run Record sink are now Support Level `verified`.

### QA (`qa-plan` and `manual-qa`)

- **Multi-session videos in Scenes:** a scenario carries a **Story:**, one sentence per Scene. The MP4 cuts between Sessions, with a Title card per Scene, and shows a role's sign-in on camera ([#381](https://github.com/mnaimfaizy/agent-kit/issues/381)).
- **Multi-Surface runs:** `run.surface` may list several Surfaces, such as `[api, web]` ([#378](https://github.com/mnaimfaizy/agent-kit/issues/378)).
- **JSON placeholders:** `http.mjs` supports `{{json:<n>:<path>}}` to reuse fields from earlier responses ([#532](https://github.com/mnaimfaizy/agent-kit/issues/532)).
- **Playwright in a subfolder:** `run.playwright` (and `--playwright-dir`) resolves Playwright from a frontend subdirectory ([#533](https://github.com/mnaimfaizy/agent-kit/issues/533)).
- **Rate limits:** a `429` (or `503` with `Retry-After`) retries the scenario once when the wait is 60 seconds or less, and otherwise leaves it for a person ([#538](https://github.com/mnaimfaizy/agent-kit/issues/538)).

### Fixed

- Skills, agent instructions, `examples/patterns/pr-pipeline/pr-runner.sh` and the reusable workflows write labels, bodies, assignees and reviewers through `gh api` REST, so older `gh` CLIs no longer fail with the `projectCards` GraphQL error ([#389](https://github.com/mnaimfaizy/agent-kit/issues/389)). If you copied `pr-runner.sh`, apply the same update.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-beta.11` and copy every path in `kit-owned-paths.txt` from the same tag. See `docs/adopt.md`.
