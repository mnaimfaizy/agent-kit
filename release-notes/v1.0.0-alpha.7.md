Security pre-release for [GHSA-6c8q-c2xg-w3fh](https://github.com/mnaimfaizy/agent-kit/security/advisories/GHSA-6c8q-c2xg-w3fh). It stops the implementer from pushing workflow changes and closes a gap in read confinement. Upgrade the `uses:` pins and the copied files together.

### Consumer action

- **Required:** re-copy `.github/agent-runtime/` from this tag. Implement loads the new `implementer.settings.json` and push guard, and fails with a message if they are missing.
- **Recommended:** before granting `extra_allowed_tools` that run repository code, protect your default branch and release tags with rulesets the Claude GitHub App cannot bypass.

### Security

- The implementer is denied edits under `.github/workflows/` and `.github/actions/`, and a pre-push hook refuses any push whose branch touches those paths.
- Read confinement judges Glob's pattern as well as its path.
- Plan and security audit deny `Bash` outright.

### Also in this release

- Per-flow model variables (`CLAUDE_MODEL_PLAN`, `_IMPLEMENT`, `_REVIEW`, `_AUDIT`), falling back to `CLAUDE_MODEL`.
- The audit's token preflight no longer needs a draft advisory to exist; a failed publish retries, then emails the full report when `notify_email` is on.

See `CHANGELOG.md` for the full list. Pin reusable workflows with `uses: <owner>/agent-kit/.github/workflows/<file>@v1.0.0-alpha.7` and copy skills plus `.github/agent-runtime/`, `.github/security-audit/`, and `.github/agent-pipeline/` from the same tag. See `docs/adopt.md`.
