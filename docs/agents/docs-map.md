# Docs map

Which pages describe each area of Agent-kit's code. The `code-review` skill's Standards pass reads it to find the pages a change may leave stale (a **Docs-impact finding**, [ADR 0010](../adr/0010-doc-facts-are-generated-and-renames-are-registered.md)). When you change an area, check its pages; when a page starts describing an area, add it to that row.

History (`CHANGELOG.md`, `release-notes/`, `docs/adr/`) keeps old names on purpose and is never listed. Rows pair areas with pages by subject: a page may describe a file's behaviour without naming the file, so read it for the concept, not only the file name. `docs/reference.md` and every Generated block (between `<!-- generated:<fact> -->` markers) are generated: regenerate them rather than editing them, with `scripts/gen_workflow_reference.py` and `scripts/gen_doc_blocks.py`.
