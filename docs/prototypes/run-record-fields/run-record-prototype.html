Run Record prototype

The question: if a Run Record held only the fields that are safe to publish (counts, ids, times, outcomes, each human intervention with its kind), could it still answer what you'd want to know about a past run? Which steps needed you and why, how long each Delegation and the whole run took, review rounds, CI failures, Rulings, QA? Each record below was derived by hand from a real run folder. Every question you ask shows its answer, and anything the record can't answer.
